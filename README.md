# Projeto de Análise de Vendas com SQLite

## Sobre o projeto

Projeto desenvolvido com SQLite com o objetivo de praticar e demonstrar conhecimentos em SQL, modelagem de bancos de dados relacionais e análise de dados.

O banco de dados utiliza informações fictícias de clientes, produtos, fornecedores, categorias, pedidos, itens de pedidos e pagamentos.

## Tecnologias utilizadas
- SQLite
- SQL
- DB Browser for SQLite

## Estrutura do banco de dados

O banco possui sete tabelas:
- Clientes
- Produtos
- Categorias
- Fornecedores
- Pedidos
- Itens de pedidos
- Pagamentos

## Conhecimentos aplicados

- Criação e manipulação de tabelas
- Chaves primárias e estrangeiras
- JOINs
- GROUP BY e HAVING
- Funções de agregação
- CASE WHEN
- Subconsultas
- CTEs (WITH)
- Funções de janela (LAG e DENSE_RANK)

## Como executar

1. Clone este repositório.
2. Abra o arquivo `database/vendas.sqlite` utilizando DB Browser for SQLite.
3. Para recriar o banco, execute os scripts da pasta `sql`, respeitando a ordem numérica.
4. Execute as consultas para explorar os dados.

## Objetivo

Desenvolver habilidades em SQL e construir um projeto prático para portfólio profissional na área de análise e engenharia de dados.
